# 🚀 Projects:

### ☕ [BrewMap — Café Finder](https://github.com/paaraskokate/cafe-finder)
A dark-themed, single-page web app that finds nearby cafés using free, open-source map data. Search by location or use your current location, browse detailed café info (ratings, hours, amenities, photos), and get turn-by-turn directions — no paid API keys required.
- **Tech:** Leaflet.js, OpenStreetMap, Overpass API, Photon Geocoding, OSRM Routing, Mapillary
- **Live Demo:** [brewmap-taupe.vercel.app](https://brewmap-taupe.vercel.app)

### 🏥 [MediScheduler — Healthcare Appointment Scheduler](https://github.com/paaraskokate/MediScheduler)
A full-stack healthcare appointment scheduling system with role-based access for patients, doctors, and admins. Patients can book appointments based on real-time doctor availability, doctors can manage their schedules, and the system automatically handles room assignment and prevents double-booking.
- **Tech:** Django REST Framework, React, Material UI, JWT Authentication
- **Features:** Role-based auth, real-time slot booking, appointment status tracking
